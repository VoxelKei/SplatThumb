# Security Policy

SplatThumb parses untrusted files inside Windows Explorer's thumbnail process, so we treat
crashes, hangs, and out-of-bounds reads on malformed input as security bugs.

## Reporting a vulnerability

Please report privately through GitHub:
**Security** tab → **Report a vulnerability** on this repository.

Do not open a public issue for security problems. If possible, include a small file that
reproduces the problem. Please do not attach real-world scans that may show people or places.

## Supported versions

Only the latest release receives fixes.
